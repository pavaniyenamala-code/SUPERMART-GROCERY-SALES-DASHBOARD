# Supermart Grocery Sales Dashboard

## Project Overview
This project analyzes supermarket grocery sales data using Excel and WPS Spreadsheets. I created PivotTables, charts, KPI cards, and a dashboard to understand sales performance, profitability, discounts, and city-wise performance.

## Tools Used
- Microsoft Excel / WPS Spreadsheets
- PivotTables and PivotCharts
- Excel formulas
- Data visualization and dashboard creation

## Project Objectives
1. Analyze sales performance by category and subcategory.
2. Understand sales trends over time.
3. Compare profit across regions and categories and analyze discounts.
4. Analyze city-wise sales and profitability.

## Dashboard Features
- Total Sales, Total Profit, Total Orders, and Profit Margin KPIs
- Category-wise and region-wise sales charts
- Sales trend chart
- Profit by Region and Category chart
- Average Profit by Discount chart
- City-wise Sales chart

## Key Insights
- Snacks generated the highest category profit.
- West region generated the highest regional profit.
- Average profit fluctuated across discount levels without a consistent trend.
- Kanyakumari had the highest city sales, with a profit margin of approximately 24.37%.
- The dataset covers cities in Tamil Nadu.

## Business Recommendations
- Review pricing, costs, and discounts in high-sales but relatively low-margin cities.
- Investigate category-level profit differences to identify improvement opportunities.
- Monitor discount performance before making pricing decisions.
